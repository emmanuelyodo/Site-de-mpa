# Mission Apostolique de Pentecôte (M.P.A. Togo)

Site officiel de la Mission Apostolique de Pentecôte au Togo (Temple du Rocher des Âges & Temple Ebenezer).

## 🚀 Déploiement Vercel

Ce projet est une application web moderne (SPA) prête à être déployée directement sur **Vercel**.

## 📁 Structure du projet

- `index.html` : Structure HTML5 sémantique et conteneur SPA
- `css/main.css` : Design system et styles d'interface
- `js/data.js` : Gestionnaire de données et état de l'application (localStorage)
- `js/pages.js` : Composants et rendu dynamique des pages
- `js/admin.js` : Espace d'administration (gestion des prédications, affiches et livres)
- `js/app.js` : Routeur SPA et initialisation de l'application
- `vercel.json` : Configuration de déploiement Vercel (URLs propres & sécurité)

## 🛠 Lancement local

Ouvrez simplement `index.html` dans un navigateur web ou utilisez un serveur local (ex: Live Server).
